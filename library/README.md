# IndusTrack image library

Photos and product screens the content agent can use in social posts.

Licensed stock photos are NOT here: they live in a private library (industrack-leads repo, media-library/stock) and are referenced as `photo: "private:stock/<file>"`, so only finished post images become public. This repo is public, so only add images you're happy to have public (they end up on social media anyway).

## Folders
- `hvac/`: rooftop units, chillers, boilers, techs working on HVAC equipment
- `plumbing/`: commercial plumbing work, mechanical rooms, piping
- `electrical/`: panels, switchgear, electricians at work
- `mechanical/`: mechanical rooms, large equipment, industrial sites
- `people/`: technicians, office staff, team photos (only people who agreed to be in marketing)
- `office/`: dispatch desk, office work, screens
- `buildings/`: commercial buildings, sites, property exteriors
- `product/`: real IndusTrack screenshots (desktop and mobile)

## Tips
- JPG, at most about 2,500 pixels on the long side (keeps the repo small). Upload up to 100 files at a time in GitHub: open a folder, then Add file > Upload files.
- Name files plainly, e.g. `rooftop-unit-tech-winter.jpg`.
- Avoid photos with competitor logos, customer names you don't have permission to show, or readable private info.

The content agent keeps `library/index.csv` (file, folder, what's in it, good for) up to date after new uploads.
